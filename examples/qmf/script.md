## 第二章 Theorem 1 & 2（01:39–04:00，561 字）

### 2-1｜01:39–02:02｜90 字

**口播**：动态融合凭什么更好？先定义要比的量：模型在新数据上的平均损失，叫泛化误差。它没法直接算，理论的办法是找它的天花板，即上界。为好分析，论文只考虑二分类、logistic 损失，即二分类交叉熵，以及加权求和式的晚期融合。

**画面**：字幕卡“泛化误差 = 新数据上的平均损失”。一条“真实误差”曲线上方压着一块半透明“天花板”，标“上界”。右下角列出设定：二分类 y ∈ {−1, 1}、logistic 损失、晚期融合（论文式 1；第 3.2 节 Basic setting）。logistic 损失的式子是标准形式，论文正文没有写出。

```latex
\mathrm{GError}(f)=\mathbb{E}_{(x,y)\sim\mathcal{D}}\big[\ell(f(x),y)\big],\qquad f(x)=\sum_{m=1}^{M} w^m\, f^m\big(x^{(m)}\big),\qquad \ell(s,y)=\ln\!\big(1+e^{-ys}\big)
```

### 2-2｜02:02–02:22｜79 字

**口播**：推导分三步。第一步，logistic 损失是凸函数，形状像只碗，所以先把各路预测加权混合再算损失，不超过先算各路损失再加权平均。这要求权重都不小于零、加起来等于 1，论文推导没写出这个前提。

**画面**：一条碗形曲线，取两点连弦；动画对比“先混合再算损失”（曲线上的点）与“先算损失再混合”（弦上的点），前者始终在下。角标“附录 A.1 式 20”；红字批注“需要 w ≥ 0 且 Σw = 1（论文未写出）”。

```latex
\ell\Big(\sum_{m} w^m f^m\big(x^{(m)}\big),\,y\Big)\ \le\ \sum_{m} w^m\,\ell\big(f^m(x^{(m)}),\,y\big)\qquad \big(w^m\ge 0,\ \textstyle\sum_m w^m=1\big)
```

### 2-3｜02:22–02:34｜52 字

**口播**：第二步，两边取期望，每一路都变成“权重乘损失”的期望。用一条概率恒等式拆开：乘积的期望，等于期望的乘积，加上两者的协方差。

**画面**：附录式 21 → 23 逐行出现；“乘积的期望”裂成两块色块：期望的乘积（蓝）+ 协方差（橙）。

```latex
\mathbb{E}\big[w^m \ell^m\big] = \mathbb{E}\big[w^m\big]\,\mathbb{E}\big[\ell^m\big] + \mathrm{Cov}\big(w^m,\ell^m\big)
```

### 2-4｜02:34–03:06｜128 字

**口播**：第三步，每一路损失的期望换成单模态的经典泛化界：训练误差，加 Rademacher 复杂度，加随样本增多而变小的尾项。Rademacher 复杂度可理解为这类模型拟合纯随机标签的本事，本事越大越可能在死记硬背。除尾项外，上界分三块：加权训练损失，叫损失项；加权复杂度，叫复杂度项；各路权重与损失的协方差，叫协方差项。

**画面**：先出单模态泛化界（附录 A.1）。讲到 Rademacher 时插入小动画：一列随机 ±1 标签，模型曲线拼命去拟合，拟合得越好，旁边“复杂度”柱越高。然后 Theorem 1 式 2 完整出现，三个下括号依次着色：Term-L（损失项）、Term-C（复杂度项）、Term-Cov（协方差项），尾项灰色；角标“以至少 1 − δ 的概率成立”。

```latex
\mathbb{E}\big[\ell^m\big] \le \hat{E}(f^m) + \mathfrak{R}_m(f^m) + \sqrt{\frac{\ln(1/\delta)}{2N}}
```

```latex
\mathrm{GError}(f) \le \underbrace{\sum_{m=1}^{M} \mathbb{E}(w^m)\,\hat{E}(f^m)}_{\text{Term-L}} + \underbrace{\sum_{m=1}^{M} \mathbb{E}(w^m)\,\mathfrak{R}_m(f^m)}_{\text{Term-C}} + \underbrace{\sum_{m=1}^{M} \mathrm{Cov}(w^m,\ell^m)}_{\text{Term-Cov}} + M\sqrt{\frac{\ln(1/\delta)}{2N}}
```

### 2-5｜03:06–03:44｜149 字

**口播**：定理 2 比较静态和动态的上界，前提有二：一是式 5，动态权重的平均值等于静态权重；二是两边单模态网络结构相同，论文据此认为训练误差和复杂度也相同。于是前两项打平，胜负手是协方差项：静态权重是常数，协方差恒为零；动态融合若做到某一路损失越大、权重越小，即相关系数不大于零，因协方差与相关系数同号，上界就不高于静态；真负相关，上界就被压低。

**画面**：左右两栏“静态 / 动态”，三项逐行对比。前提 1（式 5）、前提 2（同结构 → Ê 与 𝔑 相同，附录式 25–26）依次亮起，Term-L、Term-C 两行显示“=”；Term-Cov 一行：静态栏“= 0”，动态栏“≤ 0”。插入散点小动画：横轴损失、纵轴权重，点云向右下倾斜，标 r < 0。角标“Theorem 2，式 4–6；附录 A.2”。

```latex
\mathbb{E}\big(w^m_{\text{dynamic}}\big) = w^m_{\text{static}}\quad(5),\qquad r\big(w^m_{\text{dynamic}},\ \ell(f^m)\big)\le 0\quad(6)
\;\Longrightarrow\;
\mathcal{O}\big(\mathrm{GError}(f_{\text{dynamic}})\big)\le \mathcal{O}\big(\mathrm{GError}(f_{\text{static}})\big)\quad(4)
```

**口播**：只靠能量相关性不够强，作者加了正则项。正则化，就是在交叉熵之外往总损失里加一项可求导的惩罚，把模型推向想要的性质，可按需设计。这里要的是：历来越难学的样本，权重越小。为何看“历来”？深度网络参数多到能背下全部训练样本，包括脏的，这叫过参数化；训练后期，每个样本的当期损失都接近零。想一想：只在最后一个 epoch 记录会怎样？

### 4-6｜06:40–07:12｜132 字

**口播**：正则项是成对排序损失：权重较大者的平均损失，减去较小者的，加上权重差的绝对值，再和零取大。设甲的平均损失 0.2，乙 1.0。顺序对时，甲权重 0.7、乙 0.4：0.2 减 1.0 加 0.3 得负 0.5，取零，无梯度。顺序反时，甲 0.4、乙 0.7：1.0 减 0.2 加 0.3 得 1.1，梯度下降推高甲、压低乙，直到不再颠倒。
