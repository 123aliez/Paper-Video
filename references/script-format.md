# 脚本文件格式

`scripts/script_tool.py` 按这个格式解析脚本、导出 `shots.json`，格式错了配音和动画都无法对齐。完整范例：`examples/qmf/script.md`。

文件名：`<短名> 论文讲解视频脚本（约 N 分钟）.md`，放在 PDF 所在的工作目录。

## 骨架

````markdown
# <短名> 论文讲解视频脚本（9 分 48 秒）

<日期> · <作者>

## 制作说明

全片 N 个镜头、口播 M 字，按 240 字/分折算 X 分 Y 秒；（与计划的偏差）。

| 章节 | 时间码 | 口播字数 | 时长 | 计划 |
| --- | --- | --- | --- | --- |
| 一 开场与痛点 | 00:00–01:39 | 397 | 1 分 39 秒 | 约 1.5 分 |
| …… | | | | |
| 合计 | 00:00–09:48 | 2342 | 9 分 48 秒 | ≤ 10 分 |

- **字数口径**：按念出来的音节计。汉字每字 1；数字按中文读法（75.61 读作“七十五点六一”，计 6）；英文缩写按字母数（MVSA 计 4），英文单词按音节（Table 计 2）；标点不计。
- **时间码**：每个镜头的字数 ÷ 4 字/秒逐镜累加，取整到秒。
- **符号**：（视频中统一改记的符号，及其与论文写法的对应）
- **数字来源**：（多个表格不一致时以哪个为准）
- **口播与画面**：口播里不出现符号，公式用中文念出；公式、推导和图表特写都写在“画面”里，LaTeX 用公式块给出。

**口播**：一段连续的口播，以。？！结尾。

**画面**：具体、可执行的画面描述：出现什么、按什么顺序、和口播的哪个词同步、出处角标、红色警示标签。

```latex

```

### 1-2｜00:20–00:44｜98 字

……

### 4-4｜05:46–06:23｜139 字（末尾留白 2 秒）

（标题末尾的“留白 N 秒”会让这个镜头在口播结束后多停 N 秒，适合抛出问题让观众想一想。）

脚本（口播与画面）里的每个数字都已对照 PDF 原文核实；演示数字是自拟的，已用代码复算。

| 数字 | 含义 | 出处 | 镜头 |
````

## 解析规则（script_tool.py）

- 章标题：`## 第X章 标题（……）`，括号部分可省略。章标题去掉“第X章”后的文字，就是画面左上角标签和章节标题卡上显示的文字，所以要短（≤ 14 个字）。
- 镜头标题：`### <章号>-<序号>｜……`，镜号必须连续（1-1、1-2……2-1……），场景类名据此生成：`1-2` → `S1_2`，写在 `ch1.py`。
- `**口播**：` 后面到 `**画面**：` 之间是口播（可以跨行，会被拼成一段）；`**画面**：` 后面到下一个标题之间都是画面。
- `## 附录` 开头的章节不参与镜头解析。
- Markdown 转义（如 `f\*`）在导出时会被还原。

## 时长预算

成片时长 ≈ 4 秒片头 + 4 秒片尾 + 每镜 0.8 秒间隙 + 留白 + 口播字数 ÷ 4.2（晓晓 +6% 实测）。10 分钟以内的视频，口播大约 2300–2400 字、25 个镜头左右。`script_tool.py check` 会直接给出预计成片时长。
